HANMOTORS — RU / ET / EN + WEB3FORMS

Open index.html, or upload the contents of this directory to static hosting.
All CSS, JavaScript and image files are included. External dependencies: Google Fonts and Web3Forms submission service.

WEB3FORMS
-----------
The form under #booking submits client-side to https://api.web3forms.com/submit
The public access key is embedded as provided by the website owner.
All three languages are supported. Name, phone, service and data-processing consent are required.
On submit the visitor stays on the website and sees localized success/error feedback.
After successful submission the visitor will be contacted to agree on an appointment; this is not automatic booking.

IMPORTANT: The access key is public by design. Confirm that it is activated, linked to the correct recipient mailbox and that emails are not being filtered as spam. If Web3Forms requires domain authorization, add the actual site domain in the Web3Forms dashboard.
No real Web3Forms email was sent during package testing.
Before going live, submit one real request on your deployed domain and check delivery.
